#  Next Word Prediction using LSTM

A deep learning application that predicts the next word in a sentence using an LSTM (Long Short-Term Memory) neural network.

##  Features

- Predicts the next word based on user input
- Uses an LSTM deep learning model
- Text preprocessing with a tokenizer
- Streamlit web interface
- Simple and interactive UI

##  Technologies Used

- Python
- TensorFlow / Keras
- LSTM
- NumPy
- Streamlit
- Pickle
